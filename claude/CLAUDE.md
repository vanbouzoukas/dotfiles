# CLAUDE.md

## Principles

- Use the defaults. Change config only when the default can't do what's needed.
- Before adding a config option, plugin, dependency or custom script, check
  whether the tool already does it out of the box. Keep config files and
  dependencies minimal.
- Stay close to standards and conventions, not custom setups.

## Commits

- Only commit when asked.
- Follow the repo's own commit rules. Without any, use
  [Conventional Commits](https://www.conventionalcommits.org), with a subject
  in the imperative whose first word is lowercase.
